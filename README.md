## 🚀 Featured Project

<div align="center">

### 🌿 CropGuard — AI-Based Crop Disease Detection

**Using technology to support healthier crops and smarter agriculture.**

</div>

CropGuard is a project focused on detecting potential crop diseases from plant images and helping users understand possible next steps for crop management.

**Project focus**

- 📸 Crop leaf image analysis
- 🔬 AI-based disease detection workflow
- 🌱 Crop disease information
- 💡 Potential treatment and prevention guidance
- 🖥️ Full-stack application development

**Technology stack**

`React` `Vite` `Python` `FastAPI` `PostgreSQL`
